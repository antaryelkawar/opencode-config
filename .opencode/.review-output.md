| 1 | 🟡 **Medium** | 12 | **Event name `"tool.execute.before"` — potential typo.** Depending on the opencode plugin API version, the correct event name may be `"tool.beforeExecute"` or `"tool.execute.before"`. | 2 | 🟡 **Medium** | 25 | **Mutates `args.command` in-place on the output object.** If the same `args` reference is shared across multiple hooks or used for logging/auditing, in-place mutation creates side effects. A safer pattern: clone, rewrite, and return a new args object. |

- Plugin file exists at `.opencode/plugins/rtk.ts` — auto-discovery path matches.
- Shell API (`$\`...\``) usage is consistent with opencode plugin conventions.

## 3. `scripts/setup.ps1` — PowerShell Setup Script

### Standards: ✅ Generally Good

- Comment-based help with `.SYNOPSIS`, `.DESCRIPTION`, `.PARAMETER`, `.EXAMPLE`.
- `$ErrorActionPreference = "Stop"` for fail-fast behavior.
- Reusable `Test-Capability` function with proper temp file cleanup.
- Clean separation of concerns: remove → env-var-only → capability test → create links.

### Issues Found

| # | Severity | Line | Finding |
|---|----------|------|---------|
| 1 | 🔴 **High** | 31 | **Link target `openspec/` does not exist.** The line `@{ Target = "$ConfigRoot\openspec"; ... }` references a path that does not exist in this repo. Creating this link will either fail silently or produce a broken junction pointing to nothing. This item should be removed from the `$Items` array or the `openspec/` directory should be created. |
| 2 | 🔴 **High** | 141–145 | **`$Matches` variable may not be populated correctly.** The pattern `$remote -match '...' | Out-Null` pipes through `Out-Null`, which can suppress the population of the `$Matches` automatic variable. The idiomatic PowerShell pattern is: |
|   |          |     | ```powershell |
|   |          |     | if ($remote -match 'github\.com[:/](.+)\.git$') { |
|   |          |     |     $Matches[1] | Set-Content $markerFile |
|   |          |     | } |
|   |          |     | ``` |
|   |          |     | As written, `$Matches[1]` may be `$null` on some PowerShell versions/editions, writing an empty string to `PARENT_REPO_URL`. |
| 3 | 🟡 **Medium** | 45 | **`cmd /c rmdir` for removing directory junctions.** Relies on `cmd.exe` which is fragile on non-Windows systems (or if `cmd.exe` is unavailable). PowerShell's `Remove-Item -Force` already handles reparse points (junctions) correctly. The `cmd /c rmdir` branch appears unnecessary. |
| 4 | 🟢 **Info** | 43 | **Bitwise check could be more explicit.** `$linkItem.Attributes -band [System.IO.FileAttributes]::ReparsePoint` evaluates to a numeric value, used as a truthy check. More idiomatic: `($linkItem.Attributes -band [System.IO.FileAttributes]::ReparsePoint) -ne 0`. |
| 5 | 🟢 **Info** | — | **Script is Windows-only.** The use of `cmd /c rmdir` and `ReparsePoint` attributes make this PowerShell script inherently Windows-specific. This is documented by the `.ps1` extension, but worth noting for cross-platform setups. |

### Consistency: ❌ Issues Found

- ❌ **`openspec/` link target missing** (item 1 above).
- ✅ `opencode.json`, `AGENTS.md`, `.opencode/`, `docs/agents/` — all exist.
- ✅ All referenced paths are properly resolved via `Resolve-Path`.
